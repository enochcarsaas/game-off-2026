# Game Off 2026 entry (working title)
A low-poly 3D arcade game made for GitHub Game Off 2026. It's plain JS and three.js, and everything is made from code.
- Build: `node build.js` → `dist/index.html` (one file; put `audio/` next to it)
- Test: `node tools/bot.js` (headless Chrome, desktop and phone)
- Controls: WASD/arrows plus Space or click to dash. On touch: drag the left side to move, tap the right side to dash. Esc pauses.
